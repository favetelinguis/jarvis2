# Context file audit reference

- **Prune first.** Keep unwritten conventions, consequential boundaries, reasons and surprising gotchas; drop stale content, duplication and facts cheaply found in the environment. Context files are a cache of those sources. In [ETH Zurich's evaluation](https://arxiv.org/abs/2602.11988), files did not generally improve task success and raised inference cost over 20% on average; results depend on the tested models and tasks, not every possible project.
- **Keep it short.** Aim well under 200 lines, not a quota. [Claude Code](https://code.claude.com/docs/en/memory) warns longer files consume attention; [Codex](https://developers.openai.com/codex/guides/agents-md/) defaults to a 32 KiB combined discovery limit. The server's 32 KiB ceiling is not a target.
- **Make guidance actionable.** Prefer specific positive, testable instructions and explain surprising constraints. [GitHub's agent-persona study](https://github.blog/ai-and-ml/github-copilot/how-to-write-a-great-agents-md-lessons-from-over-2500-repositories/) recommends explicit boundaries, executable commands and examples; include those only when they earn their context cost. That article studies custom agent personas, not a controlled experiment on repository context files.
- **Separate enforcement from advice.** Use hooks or CI for hard requirements; [Claude's memory docs](https://code.claude.com/docs/en/memory) say instruction files are context, not enforcement. Propose relocating enforcement rather than pretending prose guarantees it.
- **Disclose detail.** Link to skills for conditional multi-step procedures, docs for reference and rationale, or scoped rules for narrow paths. The [AGENTS.md format](https://agents.md/) allows nested files with closer instructions taking precedence; this card proposes only the root file, so recommend nested changes to the human rather than writing them.
- **Keep it current.** Add a rule when a mistake repeats and delete it when code or automation makes it redundant. Claude's [memory guidance](https://code.claude.com/docs/en/memory) recommends reviewing recurring mistakes and moving narrow procedures into skills or scoped rules.
- **Compatibility is the human's decision.** Claude Code v2.1.277+ can read AGENTS.md when no project CLAUDE.md takes precedence; older or differently configured sessions may need `@AGENTS.md` in CLAUDE.md. See [Claude's discovery rules](https://code.claude.com/docs/en/memory#agents-md). [Cursor](https://docs.cursor.com/context/rules), [Copilot](https://docs.github.com/en/copilot/how-tos/configure-custom-instructions/add-repository-instructions), and [Gemini CLI](https://geminicli.com/docs/cli/gemini-md/) also have their own scoped instructions or configurable filenames. Describe needed follow-up in changes; never edit those files.
